- Reopen (fresh <foliate-view> instance, fresh File object, default typography/size):
  CFI exact match TRUE, rendered text exact match TRUE. Strongest, cleanest result.
- Typography change (220% font) and resize (220x700 container) both: goTo(savedCfi)
  succeeds and lands in the SAME section (section match true), but the CFI value
  reported back by the `relocate` event afterward is NOT byte-identical to the
  requested savedCfi - it reflects the current page/view boundary, not the exact
  requested anchor. Implementation nuance: for stable progress restore, goTo(cfi)
  is reliable for navigating TO the correct content, but do not assume
  view.lastLocation.cfi will echo back byte-identical to a previously-saved CFI
  after a typography/resize change - re-derive position from the DOM/content,
  don't rely on CFI string equality as the correctness check.
